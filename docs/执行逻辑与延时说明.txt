羁绊I丶无限月读宏 - 执行逻辑与延时说明

一、核心模型
每个流程最多 8 个 ID，执行顺序固定为 ID1 -> ID2 -> ... -> ID8。
每个 ID 的“动作占用”由程序按动作类型自动累计，“等待ms”由用户手动设置。
组合时长 = 动作占用 + 等待ms。

当前使用的耗时类型：
普通键耗时 / 技能键耗时 / F1耗时 / F2-F3耗时 / NPC点击耗时 / 公屏耗时 / NPC移鼠耗时 / 技能移鼠耗时。

注意：下面写的“增加某某耗时”，意思是把这段时间记到刚刚执行的当前动作上。因为流程是串行的，当前动作占用时间结束后，下一动作才会开始。

二、每个 ID 的总顺序
如果 ID 未启用：
-> 跳过

如果 ID 已启用：
-> 动作占用清零
-> 执行“组前类型”
-> 执行“刷本选择”
-> 当前 ID 动作全部结束
-> 等待该 ID 的“等待ms”
-> 进入下一个 ID

三、组前类型
组前类型 = 无
-> 不执行动作

组前类型 = 按键
-> 按一次填写的按键
-> 如果是 F2/F3：增加 F2-F3耗时
-> 其他按键：增加普通键耗时

组前类型 = 公屏
-> Enter
-> 输入填写的命令
-> Enter
-> 增加公屏耗时

公屏内部的 Enter -> 文本 -> Enter 连续快速发送，中间不插入普通键、点击或移鼠耗时。

四、刷本选择内部逻辑
刷本选择 = 无
-> 不执行刷本动作
-> 直接进入等待ms

刷本选择 = 某个刷本项
-> 鼠标移动到该刷本项绑定的 NPC 点击点
-> 增加 NPC移鼠耗时
-> 左键点击 NPC
-> 增加 NPC点击耗时
-> 按 NPC 菜单动作键
-> 如果动作键是 F2/F3：增加 F2-F3耗时
-> 其他动作键：增加普通键耗时
-> 执行技能/装备自动释放逻辑

五、技能/装备自动释放逻辑
释放类型 = 无
-> 不释放
-> 不按 F1
-> 刷本项结束

释放类型 != 无
-> 检查是否已采该刷本项的技能鼠标点
-> 按 F1 选中英雄
-> 增加 F1耗时
-> 鼠标移动到技能/装备鼠标点
-> 增加 技能移鼠耗时
-> 按释放键/槽位映射键
-> 释放键使用物理扫描码 down/up 发送
-> 释放键按住时长由 技能键耗时 决定
-> 如果释放键是 F2/F3：增加 F2-F3耗时
-> 其他释放键：增加技能键耗时
-> 刷本项结束

重要：
1. 脚本不再提供落点开关。
2. 脚本不会点击技能鼠标点。
3. 自动施法需要开启平台内快捷施法。
4. 技能鼠标点只是让鼠标先到目标位置，随后由平台快捷施法在该位置完成释放。
5. F1 只在释放类型不为“无”时触发，用于尽量避免 NPC 菜单选中状态影响释放键。
6. 如果手动 F1 后仍然插旗，主要检查平台快捷施法、释放键映射、技能是否被游戏当前状态接管。

六、常见例子：按 F2 + 家里挑战自我x5 + 自动释放技能 Q
按 F2
-> 增加 F2-F3耗时
-> 移动鼠标到家里挑战 NPC 点
-> 增加 NPC移鼠耗时
-> 左键点击 NPC
-> 增加 NPC点击耗时
-> 按“家里挑战自我x5”的 NPC 动作键
-> 增加普通键耗时或 F2-F3耗时
-> 按 F1 选中英雄
-> 增加 F1耗时
-> 移动鼠标到技能鼠标点
-> 增加 技能移鼠耗时
-> 按技能释放键 Q
-> Q 按住时长 = 技能键耗时
-> 动作占用累计完成
-> 等待ms
-> 执行下一个 ID

七、默认建议
普通键耗时：40ms
技能键耗时：100ms
F1耗时：80ms
F2-F3耗时：200ms
NPC点击耗时：100ms
公屏耗时：500ms
NPC移鼠耗时：30ms
技能移鼠耗时：80ms

如果 NPC 菜单来不及打开，优先加 NPC点击耗时。
如果移动到 NPC 后点击偏，优先加 NPC移鼠耗时，建议不要低于 20-33ms。
如果自动释放时出现插旗、命令卡没切回英雄，先确认手动 F1 是否有效，再调整 F1耗时。
如果鼠标到技能鼠标点后技能释放位置不稳，优先加 技能移鼠耗时。
如果技能键没有被平台/游戏吃到，调整 技能键耗时；这个值现在直接控制释放键按住多久。
如果 F2/F3 传送后下一步太快，优先加 F2-F3耗时。
如果整组结束后进入下一个 ID 太快，加该 ID 的等待ms。
