羁绊I丶无限月读宏 - 安装使用说明

一、文件说明
1. war3_macro_gui.exe
   已封装 AutoHotkey v2 运行环境，推荐右键“以管理员身份运行”。
2. war3_macro_gui.ahk
   主脚本，和 exe、icon 文件放在同一文件夹。
3. 启动宏配置器.bat / 管理员启动宏配置器.bat
   启动脚本。新机器上建议优先用管理员方式启动，避免游戏窗口权限高于脚本导致绑定或发键失败。
4. 执行逻辑与延时说明.txt
   单独说明流程 ID、刷本项、自动施法、技能鼠标点和各类耗时的真实执行顺序。

二、首次使用
1. 解压整个文件夹到任意位置。
2. 右键 war3_macro_gui.exe 或“管理员启动宏配置器.bat”，选择“以管理员身份运行”。
3. 不加载配置时，所有流程热键、刷本按键、技能鼠标点、家里 NPC 坐标、技能/装备映射默认都为空；停止热键默认 Z。
4. 第一次保存某个英雄时点“保存为新英雄”，用英雄名称命名；程序会自动创建 profiles 文件夹。
5. 已读取英雄配置后，点“保存当前配置”会直接覆盖当前读取的 ini 文件。

三、当前发行版方法
1. 本版本仍使用固定耗时模型，不引入图像识别或状态检测算法。
2. NPC 点击使用地图世界坐标投影，技能/装备自动释放继续使用“技能鼠标点”。
3. 自动释放不点击技能鼠标点，只把鼠标移动过去，再按技能/装备释放键。
4. 自动施法需要开启平台内快捷施法。
5. 释放类型为“无”时不会按 F1，也不会执行自动释放。
6. 释放类型不为“无”时，会先按 F1 选英雄，再移动到技能鼠标点，再按释放键。
7. 技能/装备释放键使用物理扫描码方式发送，按下时长由“技能键耗时”决定；没有 50ms 底线，也没有 100ms 封顶。

四、常用步骤
1. 进入地图后按 F9 完成本局绑定、初始化和人物镜头锁定；也可以点击界面的“绑定游戏窗口并初始化”。
2. 打开“平台按键映射表”，填写技能/装备映射。装备必须有按键映射，不再采装备坐标。
3. 需要补充屏幕鼠标点时，使用面板中的对应记录按钮，不再占用 F5-F8。
4. 配置 7 个刷本项的动作键、释放类型、释放键/槽位、技能鼠标点。
5. 配置 8 个自定义流程；流程名称可自改，执行顺序固定按 ID 1 到 ID 8。
6. 触发键、停止热键、刷本动作键、释放键旁边的“采”支持键盘、鼠标中键、鼠标侧键。

五、耗时说明
1. 普通键耗时：组前按键、NPC动作键等普通按键动作完成后的占用时间，默认 40ms。
2. 技能键耗时：自动释放时，技能/装备释放键的按住时长，默认 100ms。填 1 就按住约 1ms，填 1000 就按住约 1000ms。
3. F1耗时：仅当释放类型不为“无”时，释放前按 F1 选中英雄后的占用时间，默认 80ms。F1 自身仍保留最低按键时长，用于保证选英雄更容易被游戏吃到。
4. F2/F3耗时：直接按 F2 或 F3 后的占用时间，默认 200ms。
5. NPC点击耗时：左键点击 NPC 后，到按 NPC 菜单动作键之前的占用时间，默认 100ms。
6. 公屏耗时：Enter -> 文本 -> Enter 发送完成后的占用时间，默认 500ms。
7. NPC移鼠耗时：鼠标移动到 NPC 点之后、点击 NPC 之前的占用时间，默认 30ms。建议不要压到 1ms，War3 需要按帧读取鼠标位置。
8. 技能移鼠耗时：鼠标移动到技能/装备鼠标点之后、按释放键之前的占用时间，默认 80ms。
9. 等待ms：当前 ID 所有动作执行完之后额外等待多久，用户可手动修改。
10. 组合时长ms：灰色不可改，公式为 组合时长 = 动作占用 + 等待ms。

六、初始化与绑定快捷键
F9：绑定 War3、读取本局参数并自动按 F1 两次锁定人物和镜头
Ctrl+Alt+B：在当前前台窗口直接绑定游戏窗口
停止热键：默认 Z。单按停止并暂停触发；连续双按停止热键重新启用触发。
Esc：不占用，保留给游戏原本功能。

七、注意事项
1. 坐标是屏幕坐标，不是游戏内地图坐标。
2. 本版本暂不做图像识别/文字识别/状态检测，所以仍需要合理设置各类耗时。
3. 组前类型选“公屏”时，会快速执行 Enter -> 命令 -> Enter；中间不插入普通键或点击耗时。
4. HC/HG 这类公屏命令走公屏耗时；直接按 F2/F3 才走 F2/F3耗时。
5. 如果 ID 之间衔接不稳，优先把 NPC移鼠耗时放到 20-33ms 以上，再调整该 ID 的等待ms。
6. 本工具只做手动热键触发的键盘鼠标宏，不读取游戏内存。
