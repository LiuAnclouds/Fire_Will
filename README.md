# Fire Will

Warcraft III / 羁绊 I visual macro configurator.

## 开发目录

这个目录用于后续开发和版本管理，当前包含：

- `war3_macro_gui.ahk`：主 GUI 宏配置器源码
- `war3_npc_macro.ahk`：较早的 NPC 宏模板
- `profiles/`：英雄/流程配置档案
- `info/`：识别和操作参考图片
- `recognition_probe.py`：识别测试辅助脚本
- `docs/`：安装使用说明与执行逻辑说明

## 本地运行

安装 AutoHotkey v2 后，可以直接运行：

```powershell
.\war3_macro_gui.ahk
```

也可以双击 `启动源码宏配置器.bat`。
